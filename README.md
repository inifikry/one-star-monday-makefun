# One Star for Monday

A one-star review of Monday, written as if Monday were a restaurant.

Running `main.py` writes a single line to `/output/entry.txt`:

> One star. Waited an hour for a table, the coffee came cold, and Monday's special was a 9 a.m. meeting.

One line, 20 words, plain text — short enough to screenshot into the group chat.
